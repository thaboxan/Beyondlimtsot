# Beyond Limits OT

A professional website for Beyond Limits OT - Occupational Therapy services in East London, South Africa.

![Beyond Limits OT](https://img.shields.io/badge/Beyond%20Limits-OT-C75B39)
![Status](https://img.shields.io/badge/Status-Live-2D5A47)

## About

Beyond Limits OT is dedicated to providing compassionate, culturally sensitive occupational therapy services. This website serves as the digital presence for the practice, allowing clients to learn about services and book appointments.

**Tagline:** *"Empowering you to live beyond limits."*

## Features

- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **Modern UI/UX** - Clean, professional design with smooth animations
- **Sticky Navigation** - Smart navigation bar with animated slider effect
- **WhatsApp Integration** - Floating WhatsApp button for quick client inquiries
- **Back to Top Button** - Smooth scroll navigation
- **Contact Form** - Integrated with FormSubmit for email notifications
- **Parallax Effects** - Engaging scroll animations
- **Accessibility** - ARIA labels and semantic HTML

## Getting Started

### Prerequisites
- A modern web browser
- Python 3.x (for local development server)

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/thaboxan/Beyondlimtsot.git
   cd Beyondlimtsot
   ```

2. Start a local server:
   ```bash
   python -m http.server
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```
